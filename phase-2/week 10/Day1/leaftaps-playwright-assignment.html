03 · Generated output

TypeScript Playwright test

The generated test uses the existing USERLOGIN credential mapping and the custom fixture. It relies on Playwright's auto-waiting assertions and does not use fixed waits.

import { expect } from "@playwright/test"
import { test } from "../customFixtures/leaftapsFixture"

test.describe.serial("Leaftaps authentication and logout", () => {
    test("Login as democsr and logout", async ({ page, LeaftapsLogin }) => {
        test.info().annotations.push(
            { type: 'TestCase', description: 'Login as democsr and logout' },
        );

        // 1. Navigate to https://leaftaps.com/opentaps/
        // 2. Enter username democsr in the username field
        // 3. Enter password crmsfa in the password field
        // 4. Submit the login form
        await LeaftapsLogin.leaftapsLogin("USERLOGIN");

        // 5. Verify the authenticated Leaftaps page is displayed
        await expect(page.getByRole('heading', { name: 'Welcome Demo B2B CSR' })).toBeVisible();

        // 6. Click Logout
        await page.getByRole('button', { name: 'Logout' }).click();

        // 7. Verify the login page is displayed again
        await expect(page.getByRole('heading', { name: 'Leaftaps Login' })).toBeVisible();

        // 8. The Playwright fixture closes the browser context after the test.
    });
});

Why this matches the framework

  • Imports the repository's custom leaftapsFixture test object.
  • Uses the existing LeaftapsLogin.leaftapsLogin("USERLOGIN") method.
  • Uses the existing serial describe pattern and test annotations.
  • Uses accessible role locators and expect(...).toBeVisible().
  • Does not add fixed waits, navigation waits, or invented fixture methods.

04 · Framework gap and execution evidence

Gap analysis

The framework currently has no reusable logout method in LeaftapsMyHomePage. The selector registry contains a logoutButton entry, but no page-object method calls it.

Decision: The test uses the supplied page fixture for the Logout interaction instead of pretending that a missing page-object method exists.

Recommended framework addition

public async logout() {
    await this.click(selectors.logoutButton, "Logout", "Button");
    return this;
}

After adding this method to pages/leaftapsMyHomePage.ts, the test could replace the direct page click with await LeaftapsMyHome.logout(). This addition is optional for the generated test because the current test remains explicit and functional.
